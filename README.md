# Hi, I'm Talla Michael 👋

Backend and embedded systems engineer from Bamenda, Cameroon. I build production backends with Node.js, TypeScript and Express, and I like working where software meets hardware.

Currently doing my MEng in Computer Engineering at NAHPI, University of Bamenda.

## What I work on

- **Backend systems:** REST APIs, auth and role-based access, payment integrations, scheduling, notifications
- **IoT:** device registration and control over MQTT, remote monitoring dashboards
- **Embedded:** mmWave radar + camera sensor fusion on Raspberry Pi, Arduino firmware in C++
- **Offline-first apps:** LAN-based servers that keep working without internet and sync when they reconnect
